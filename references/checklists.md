# 自检清单全集

供 S1 诊断、S4 规范化、S5 终检调用。全部条目出自六份源文献的精读整理，出处标注于括号内。

## 1. 三问判别（S1 第一遍）

1. 它问的东西是**学界未知**的吗？（查研究文献，不是查搜索引擎）
2. 它有**知识价值**吗——回答它能否改变某个领域的理解或某个实践的做法？
3. 它能被**经验证据**回答吗？（能用数据、材料、观察裁决，而不是靠立场争辩）

三问全过才进入收窄；任何一问不过，如实告知用户问题尚未成形。

## 2. 八种问题病诊断表（S1 第二遍）

| 病名 | 症状 | 病例 | 处方 |
|---|---|---|---|
| 复合问题 | 一问两答 | "某政策的目标是什么、达成多少？" | 拆成两个问题，各配各的数据 |
| 隐藏预设 | 问题内含未经确立的前提 | "男孩几岁时停止在校成绩不佳？" | 先立预备问题确立前提 |
| 假两难 | 用"或"制造对立选项 | "全民医疗：促进平等还是降低质量？" | 拆成两个独立问题 |
| 同义反复 | 问题自含答案 | "为什么工人阶级在某些职业占比过高？"（职业即阶级的操作化） | 换问题（如跨代流动） |
| 规范问题 | 含 should / ought / better | "怎样的教育制度更好？" | 改写为可调查的事实问句 |
| 形而上问题 | 无法用数据回答 | 多数无方向的 why | 改写为 what |
| 假开放问题 | 答案已内定 | "某国人对离婚的态度如何？"（预设存在同质固定的"态度"） | 检验问题是否揭示被问者的可质疑性 |
| 修辞问题 | 靠紧张感博关注 | "风险博弈：生存空间如何扩大" | 剥掉修辞，回到内容 |

隐性规范词逐个显影：poor、effective、authoritarian、successful、satisfaction、frequent、elderly——必要时定义问题句中每个名词、动词、形容词、副词。

## 3. 终检一票否决清单（S5）

**语言层**：① 单句检验——能用一个完整句写出（写不出只说明还没打磨够）；② 小报检验——能给非专业读者写通稿。

**价值层**：③ "这有什么要紧"有硬答案；④ 三反应测试——同行听后介于"显而易见"与"荒谬"之间，做到部分接受、部分否认受众假设；⑤ 问题价值六特征（真实性、明确性、针对性、关联性、伸展性、一般性）至少过四条，其中明确性与真实性不可缺。

**结构层**：⑥ 类型标签、主子层级、四要素齐备；⑦ 概念全部操作化、有比较物。

**伦理与政治层**：⑧ 预判"挑战该假设时谁输谁赢"；⑨ 意识形态自检五问——我的目的是探索发现还是宣传维护？我的态度是期待挑战还是不期待？我的评判标准是基于立场还是证据？当对方的证据真实时，我是否愿意承认自己错了？从对立意识形态立场出发，我的问题是否仍成立？

## 4. 差异性发问九条自检（S3 第 1 层）

1. 我的问题里有具体差异性吗？能否说出"什么和什么之间在什么上的不同"？
2. 差异是否需要测量？外行能否信服我的衡量标准？
3. 信息量：问题之外我还告诉读者多少案例事实？外行是否也能问出这个问题？
4. 背后有没有结构 / 机制性因果假说？一句话能说清吗？
5. 我列出替代假说了吗？能否把本领域主要理论当替代假说？
6. 隐含假设逐个检查过了吗？
7. 我能提出几个理论假说？（只有一个且人人猜得到——太简单；很多且性质各异——太发散，收窄到具体时代 / 类型 / 人物）
8. 案例在经验或理论上重要吗？
9. 研究全程是否持续捕捉新差异、修正发问，还是只找有利证据？

## 5. 可行性三问与操作化（S4）

1. 需要什么数据？如何收集分析？收集分析将牵涉什么（时间 + 成本逐项估算，含转写量）？
2. 做不了就改问题（减少问题数或修改关键术语），准备方案 B。
3. 每个概念：定义 → 操作化 → 数据；用现成测量工具并写明版本；指标旁写一句"它丢掉了什么"。
4. 比较物三选一并写明：时间比较 / 组间比较 / 基准率。
5. Feynman 检验：不用术语、用日常语言解释每个核心概念。

## 6. 定性问题六部件对齐（S4 质性分支）

六部件：范式 / 疑问词 / 实质主题 / 场景或现象参数 / 理论视角 / 研究传统。

- 范式—视角—传统必须匹配（审稿人必查项）；"批判范式 + 认知视角 + 现象学"是缝合组合。
- 疑问词是舵：换疑问词等于换研究；who / when 多作子问题；how 有歧义（过程步骤 vs In what ways），须说清。
- 铸造技术：代入替换、工作大理石（六部件混搭表）、假想答案、假想报告体裁。
- 总问题模板：Given a [paradigm] paradigm, [interrogative] is/are [topic] in [setting] from a [perspective] perspective using [tradition] research methods?

## 7. 学术与意识形态自检（S5 伦理层）

直接问用户：我的目的是探索发现还是宣传维护？我的态度是期待挑战还是不期待？我的评判标准是基于立场还是证据？当对方的证据真实时，我是否愿意承认自己错了？从对立意识形态立场出发，我的问题是否仍成立？

## 8. 陷阱提醒

- 学生几乎总是高估所需原创性、低估范围失控——缺口通常太大而非太小。
- "没有前人做过"的论证只会引来三种猜疑；改说"位于两个此前未被交叉领域的新交叉点"。
- 创新与意义是两回事：有意义的问题通常有创新性，但不是所有创新都有意义。
- 事实与意愿混淆是经验研究大忌；没掌握资料前备好的分析框架很可能只是假设。
