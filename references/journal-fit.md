# SSCI / CSSCI 对标逻辑（教练经验层）

**诚实声明**：本文件的匹配逻辑是教练层的经验性框架，不属于问题打磨方法本身。它只给"问题形态与刊物层级的匹配思路"，不包含任何具体期刊的影响因子、分区、审稿周期或栏目设置——这些信息会过时且本 skill 不编造，使用时一律提示用户查当期官网与最新刊例。

## 1. 三条契合线

选题与期刊的匹配沿三条线判断，三条线都过才建议投：

1. **议题契合**：问题的现象层是否在该刊近年选题范围之内（读该刊近两年目录即可自核，无需依赖记忆）。
2. **方法契合**：证据形态是否是刊物常见形态（质性民族志 / 访谈研究 / 历史比较 / 定量因果 / 计算文本）。
3. **理论对话契合**：问题对话的理论对象是否是该刊读者群熟悉的对话者（问题化五层假设中质疑的层级越高，可对话的刊物面通常越宽，但也越难做深）。

## 2. 层级判断的经验规则

- **共识挑战型问题**（质疑领域默认假设、有替代假设地基）→ 具备冲更高层级刊物的潜质；但须过 S5 终检的"不荒谬"关，否则高层级刊物的第一轮筛选就过不了。
- **规范的小信息量差异性问题**（差异明确、测量可信、机制假说清楚）→ 是 CSSCI 权威刊物与 SSCI 中上游的主流形态；投稿信里把差异句与替代假说写清楚是性价比最高的动作。
- **纯描述型问题** → 通常需要附加比较物或时间纵深才能进入权威刊物视野；单纯"某群体对某事的态度"形态建议升级后再投。
- **议题热点**：热门与重要有区别；热点问题若不能通过"学界未知 + 知识价值"两关，投什么层级都不改变其价值密度。

## 3. 中英标题与语言关卡

- SSCI 投稿：标题用研究性英文表述（见 templates.md 第 5 节），摘要首句即可复述差异句；引语回译与参考文献真实性另由相应工具核验，本 skill 不承担。
- CSSCI 投稿：中文标题剥除修辞；议题表述对齐国内学科语境的通行概念译名。

## 4. 与本 skill 其他部分的边界

- 本文件只回答"问题形态 → 刊物层级"的匹配思路；
- 论文写作、润色、去 AI 化、参考文献核验、数据分析由其他 skill 承担；
- 预测某刊"会不会录用"超出本 skill 范围：只给可核实事实与匹配逻辑，不做录用预测。
