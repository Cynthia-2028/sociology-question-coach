# 正反例库

供 S1 诊断与 S3 升级时引用佐证。所有案例均出自六份源文献（经其转引的经典一并标注），使用时可向用户复述但不虚构细节。

## 1. 好问题案例库（拆解用）

| 案例 | 出处 | 拆解要点 |
|---|---|---|
| 牛为什么会走到邻家的地吃草 | 科斯（张静书转引） | 小题大做：从牲口过界纠纷推进到产权与交易成本 |
| 人是有限理性的 | Simon | 领域假设质疑（"人是理性决策者"为跨学派共识） |
| 工人为何干这么多（而非为何不卖力） | Burawoy | 因果方向逆转 |
| 若工作有意义，人们为何需要被激励 | Sievers | 意识形态假设质疑 |
| 新教在中国 1949 年前后的扩张差异 | 孙砚菲（赵鼎新文转引） | 信息量大、测量四标准、结构假说 + 替代假说 |
| 各国走向不同政治道路的差异 | 摩尔（赵鼎新文转引） | 5 国 × 3 道路 = 243 种可能组合对一种经验事实 |
| 为何组织都长得一样（而非为何如此多样） | DiMaggio & Powell（A&S 书转引） | 逆转术 |
| 墙上的制度为何没有用却到处存在 | 张静调研 | 违背常识 + 普遍存在 |
| 中国为何出现独立商人却没有转型为资本主义 | 寇恩（张静书转引） | 在既有理论预期失效处发问 |
| 认同是否只在特定情境下表达 | 对 Dutton et al. (1994) 的问题化 | 问题化六步完整示范 |

| 病例 | 病名 | 改法 |

## 3. 升级改写对照示例（S3 展示用）

**例一：从找空白到质疑假设。** 原研究问"组织形象与成员认同的关系"，其未言明假设是成员身份像俱乐部式的积极选择、个人与组织各有一套可比较的稳定属性。升级路径：言明假设 → 从批判理论、经济人假设、后结构过程观三路借力 → 替代假设为"组织认同是情境特定、利益驱动、暂时性的话语行为" → 新问题："人们是否感到自己与组织相似？若然，多常、何时？"

**例二：从过程性到差异性。** "我想知道土地改革中情感动员是怎么进行的"是照猫画虎的过程性发问；对照改写："为什么情感能驱动美国早期社会运动，但 20 世纪 60–70 年代后越来越受理性策略驱使"——差异随时间出现且指向机制。

**例三：从 why 到 what。** "为什么求助拉比"拆为"什么驱动他们求助、求什么问题"与"他们如何报告咨询体验"两个 what 问题，数据类型随之清晰。

## 4. 使用规则

1. 向用户展示正反例时，说明"好在哪里"的机制，不停留在"这是好例子"。
2. 案例中的经典（科斯、Simon 等）是二手转引，若用户要正式引用，提示回查原著。
3. 不要把案例直接改成用户的研究内容——案例用于校准判断，用户的问题必须长在用户自己的素材上。
